### Fix 2: Add Empty Data Handling to Backend

**File**: `server/routes.ts` (line 650-996)

Add early return for new users:
```typescript
app.get('/api/perform/dashboard', requireAuth, async (req, res) => {
  try {
```

### Fix 3: Add Null Checks for Date Parsing

**File**: `server/routes.ts` (around line 759, 775, 786)

Replace unsafe date parsing:
```typescript
// BEFORE (unsafe):
date: new Date(session.completedAt || session.createdAt || Date.now()).toLocaleDateString('en-GB')

// AFTER (safe):
date: (() => {
  const timestamp = session.completedAt || session.createdAt;
  if (!timestamp) return new Date().toLocaleDateString('en-GB');
  try {
    return new Date(timestamp).toLocaleDateString('en-GB');
  } catch (e) {
    return new Date().toLocaleDateString('en-GB');
  }
})()
```
